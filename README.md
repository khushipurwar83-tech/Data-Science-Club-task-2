# 🚀 Vibe Hack 2026 – Hackathon Registration Website

A modern, immersive, and responsive hackathon registration platform built as part of the **Software Development Team Recruitment – Round 1 Assignment** for the **Data Science Club (DSC), VIT Bhopal University**.

Vibe Hack 2026 combines cutting-edge frontend technologies with an engaging cyberpunk-inspired interface to deliver an intuitive and visually rich user experience. The project emphasizes responsive design, interactive animations, accessibility, and performance optimization.

---

## 🌟 Project Overview

Vibe Hack 2026 is a fictional hackathon registration platform designed to provide participants with a seamless event experience—from exploring hackathon details and problem statements to completing registration through an interactive multi-step form.

The website focuses on delivering a premium user experience through immersive visuals, smooth animations, and modern frontend development practices.

---

## ✨ Features

### 🎨 Visual & Interactive Design

- Interactive 3D particle hero background powered by Three.js
- Cyberpunk-inspired UI with a modern glassmorphism design
- Animated gradient typography and typewriter effects
- Smooth page transitions and scroll animations using Framer Motion and GSAP
- Fully responsive design for mobile, tablet, and desktop devices

---

### 📄 Website Sections

- 🏠 Hero Section with a live 3D countdown timer
- ℹ️ About section with animated statistics
- 💡 Searchable & filterable Problem Statements
- 📅 Interactive multi-day event schedule
- 🏆 Prize showcase with featured Grand Prize
- 🤝 Tier-based Sponsors section
- 📝 Multi-step Registration Form with progress tracking
- ❓ FAQ section with animated accordions

---

### 🎯 User Experience

- Fixed navigation bar with active section highlighting
- Smooth scrolling between sections
- Interactive hover animations
- Real-time form validation
- Confetti celebration after successful registration
- Mobile-friendly touch interactions
- Clean and intuitive interface

---
